# RAGFlow 导入配置注意事项

配套 skill：pdf-ragflow-split。本文件用于在拆分完成后，指导用户正确配置 RAGFlow 知识库并导入。

## 一、创建知识库（关键配置）

| 配置项 | 推荐值 | 说明 |
|---|---|---|
| Chunk 方法（解析器） | **General（通用）** | ⚠️ 不要选 Table——它只支持 XLSX/CSV/TXT，**不支持 MD** |
| Embedding 模型 | 中文模型（如 bge-large-zh-v1.5） | ⚠️ **一旦有分块就不能改**，先选好 |
| 向量数据库 | 默认（Milvus） | 不动 |
| Chunk token 数 | 256~512 | 表格合并后内容多，太小会切碎表格 |
| 重叠（Overlap） | 开启，约 10~20% | 防止跨 chunk 语义断裂 |

## 二、解析参数微调（MD 最关键）

创建知识库后在「Chunk 方法」里改 **Delimiter for text**（文本分段标识符）：

```
### ## #
```

- 分隔符用**反引号包裹**、**从长到短**排列（`###` 在 `##` 之前）。
- 作用：让 RAGFlow **按标题切块**，每个 `## 第 N 页` 章节成为完整 chunk。
- 默认分隔符（`\n!?。`）会无视标题结构乱切，这是 MD 效果差的首因。
- ⚠️ 修改设置**只对新上传文件生效**，改完需重新上传文件。

## 三、上传方式

- RAGFlow **不支持 zip 上传**（安全限制）。
- 用「上传文件夹」或**拖拽整个文件夹**到上传区——保持 text.md 与 images/ 的相对目录结构。
- ⚠️ 不要逐个选文件（会扁平化，导致 `images/xxx.png` 相对引用断链）。
- 图片文件会被自动识别为 Picture 解析器（视觉/OCR 路径）。

## 四、检索设置

- 检索模式选**混合检索**（向量 + 全文 + rerank 融合），对表格关键词召回远好于纯向量。
- 相似度阈值先用默认，跑一轮测试再调。

## 五、验证闭环

1. 上传后点「解析」，等待异步完成；确认「分块数」> 0。
2. 点文件名进入「分块列表」，抽查 2~3 个 chunk：
   - 开头是否为 `## 第 N 页` 标题（delimiter 生效）
   - 大表格是否被切碎（若切碎，调大 Chunk token 数）
3. 用 5~10 个真实问题测试（如「车站结构模型 LOD300 需要哪些信息？」），看召回片段是否指向正确表/页。
4. 不准就调整 delimiter / chunk 大小，**改一次重新上传一次**。

## 六、图片注意事项

- 图片方向问题（上下颠倒）已在拆分脚本中自动校正（transform d<0 → 垂直翻转）。
- 若 RAGFlow 某版本对 md 内嵌图片支持有限，图片不被识别：不影响文字/表格检索（text.md 中图片引用文字仍有描述），可接受。
